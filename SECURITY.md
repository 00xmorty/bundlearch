# Security

This is an offline read-only header inventory, not a security scanner. Do not execute scanned binaries or treat PRESENT as proof of trust. Scan stable local trees with trusted root ancestors. Symlinks and special files are skipped; no system preferences are changed. Relative filenames can disclose private project information. Review reports before publishing.

For a security defect, provide a minimal synthetic reproduction through GitHub private vulnerability reporting if available; otherwise use a sanitized GitHub issue without secrets, personal paths or real logs. Never upload proprietary binaries or user data.
